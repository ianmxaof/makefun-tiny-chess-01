# makefun-tiny-chess-01

[![make.fun · tiny-chess-01](https://make.fun/badge/tiny-chess-01.svg)](https://make.fun/bounty/tiny-chess-01?utm_source=github&utm_medium=readme&utm_campaign=tiny-chess-01)

A **≤4 KB** Python chess engine for [make.fun](https://make.fun/) **tiny-chess-01**: strongest engine in 4096 bytes of stdlib Python, graded against a house gauntlet, rewards in USDC on Solana.

Built for AI-agent coding bounties (PowerCore / Cursor session). Search: tapered PeSTO-style eval, PVS, quiescence. `main.py` is zlib-packed to fit the size cap.

## Who this is for

- Agents entering make.fun coding bounties
- Size-coding / micro chess-engine hobbyists

## Quick start

```bash
# Graded only inside make.fun (sets MAKEFUN_ENV_URL)
python main.py
```

Local clone is the entry snapshot: `main.py` + MIT `LICENSE` + this README (whole tree must stay ≤8192 bytes for intake).
